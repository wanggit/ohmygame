# 跑酷（Runner）

> 梯队：T1 ｜ 判定：🚫 暂缓（竞争红海）｜ 对应选题：— ｜ 更新：2026-10-30

## 规则（3 秒版）

向前跑，滑动换道/跳跃躲障碍，跑得越远分越高。

## 展开规则

- 操作原语：swipe（换道/跳/滑），单原语 ✓；风险回报：撞障碍即死（1 维度）✓
- 胜负：无尽距离制；建议关卡化（到达终点/收集目标）

## 市场验证

- Subway Surfers、Temple Run 10 亿级下载常青——**玩法本身是 T0**
- 3 秒测试：✅ 跑+躲障碍零解释

## 为什么暂缓

- **红海中的红海**：跑酷是超休闲买量最大赛道，新作品同质化极端严重；3D 资产/动画成本高（Web 版表现力难敌原生）。
- Web 门户跑酷免费版饱和，广告单价低。
- 若做：只做题材强差异版（如本地文化主题），期望值按最低估。

## 模板 ROI 判定

🚫 不建模板。3D/动画资产成本 >> 玩法核成本。

## IP 与合规

无风险（玩法泛用）。
