# 消箭头（Tap Away / Arrow Away）

> 梯队：T0（新爆款）｜ 判定：⏳ 值得模板（关卡可解生成是核心）｜ 对应选题：— ｜ 更新：2026-10-30

## 规则（3 秒版）

点击箭头使其飞走；被其他箭头挡住的点不动——把所有箭头清空即胜。

## 展开规则

- 操作原语：tap（点箭头），单原语 ✓；风险回报：错误顺序把自己堵死（1 维度）✓
- 胜负：全清 = 胜；无合法点击 = 败（死局式，可配洗牌道具）

## 市场验证

- Tap Away（Big Run Studios / Lion Studios）2022-23 爆款、2024-25 仍稳定长销；"点走被挡物"成为新经典 puzzle 语法（Seat Away 等衍生作持续进榜）
- 3 秒测试：✅ 箭头指向即"要去的方向"，被挡状态一目了然

## 实现要点

- 玩法核：箭头朝向 + 挡位射线判定 + 飞出动画，半天可写
- **关卡生成是高实现成本点**：随机布局必须保证可解（拓扑排序/回溯求解验证）+ 难度分级（最少剩余步数标定）——与水排序同属"可解性标定"家族
- 预估成本：首版 3-4 天（生成器占一半）

## 模板 ROI 判定

⏳ 值得模板（触发：确认做此品类即建）。可解关卡生成器 + 难度标定完全复用水排序范式，模板收益高。

## IP 与合规

玩法泛用无风险；箭头/方块造型自绘（不用 Tap Away 的 3D 简约风素材）。

## 变奏空间

3D 方块版、汽车/方块/动物造型、限步挑战、主题皮肤。
