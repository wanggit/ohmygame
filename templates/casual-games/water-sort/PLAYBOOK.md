# 水排序 / 颜色分类（Water Sort）

> 梯队：T0 Sort ｜ 判定：✅ 母版已建（本目录含模板代码）｜ 对应选题：A1–A3 ｜ 更新：2026-10-30

## 规则（3 秒版）

点击源管，把顶部连续同色段倒入目标管；所有管一瓶一色即胜。

## 展开规则

- 操作原语：tap（点源管 → 点目标管），单原语 ✓
- 风险回报维度：倒错会堵死自己（1 个维度）✓ 复合判定检查通过
- 胜负：全部单色 = 胜；无合法倒且未完成 = 败（死局式，无步数失败）

## 市场验证

- Water Sort 系全球长销；Sort 是 2024-25 上升最猛的 puzzle 赛道（Hexa Sort、Twisted Tangle、Block Jam 3D、Color Block Jam 先后进畅销榜）
- 3 秒测试：✅ 彩色液体归位，目标视觉自明

## 实现要点

- 玩法核：管状态机 + BFS/DFS solver（生成期可解性验证）
- 关卡：`pregen.ts` 预生成 → `levels.json`；solver 剪枝须逐条对照玩家规则、hash 不抹身份管（踩坑录）
- 难度模型：颜色数 / 空管数 / 目标步数 / 特殊管（锁管 / 冰管 / 雾管）
- 实测成本：母版七轮实测定稿；换皮约 40 分钟（A2 实测）
