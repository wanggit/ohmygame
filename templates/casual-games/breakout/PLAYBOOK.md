# 打砖块（Breakout）

> 梯队：T0 ｜ 判定：💡 直接做游戏 ｜ 对应选题：— ｜ 更新：2026-10-30

## 规则（3 秒版）

挡板反弹球，把屏幕上的砖块全部打掉。

## 展开规则

- 操作原语：drag/swipe（移动挡板），单原语 ✓；风险回报：球落底丢命（1 维度）✓
- 胜负：清砖 = 胜；丢 3 球 = 败。关卡制（砖块布局 + 道具）

## 市场验证

- 1976 年 Atari 至今 50 年常青；Arkanoid/Breakout 无数变体长销；物理反弹的 satisfying 反馈天然成立
- 3 秒测试：✅ 球+挡板+砖块零解释

## 实现要点

- 玩法核：球物理反弹 + 砖块碰撞 + 挡板，半天可写；手感（反弹角度映射挡板位置）是打磨重点
- 预估成本：1-2 天

## 手感与物理不变量（2026-11-15《球雨》复盘沉淀）

- **角度约定全项目只用一种**：发射/反弹角的 0° 基准必须统一（`atan2` 约定与「0°=正上方」混用曾让加出来的球全部水平射出、堆在底部横弹）。
- **安全阀**：任何球的垂直分量 ≥ 40% 球速（砖碰撞后与新球生成时都校正）；挡板反弹最大出射角 ≤ 60°，边缘击球不出近水平弹道。
- **不变量压测开工即写**（别等 bug）：确定性长模拟逐帧断言 球速范围 / 垂直分量下限 / 不出界 / 球数上限 / 状态有限值。动作级单测抓不到「球躺平横弹」这类体验 bug。
- **受击动画禁用绝对 scale 补间**：砖块常用 `setDisplaySize` 压扁显示，`scale: 1.12 → 1` 这类补间会把原始贴图拉回全尺寸（「大方块」bug）；基于创建时记录的基础缩放做弹跳，白闪后恢复原色。
- **球径 < 砖缝**时加分离判定 + 命中冷却，防止反弹挤进相邻砖连击。
- **逐关截图验收**：血量配色 / 砖贴图逐关不同（彩=1 血、银白=2 血、金=3 血），每关至少一张整屏截图过目，抽查不算覆盖。

## 连击与节奏配方（2026-11-17《萌兽打砖块 · Monster Smash》复盘沉淀）

- **连击链 = 唯一风险/回报维度（差异化钩子）**：碎砖连击 +1，**碰挡板不断链、只有掉球断链**；高连击加速球速（难控 = 风险）并抬分数倍率（GREAT! ×2 → AMAZING! ×3 → FEVER!! ×4 + 全屏光效）。实测最高 ×30，爽感来自"敢不敢在高球速下继续养链"。⚠️ 碰挡板清零的常规做法会让实际连击只有 1–5，与"非常多连击"卖点冲突——**连击断链规则是卖点敏感参数，设计阶段必须与用户对齐**，不要埋进长文档。
- **过关庆祝延迟过场**：清砖瞬间弹结算面板会遮住庆祝粒子。正确节奏 =「清砖 → 1.5–2s 庆祝（场面定格 + 彩带/星星/白闪 + "过关!"大字）→ 再弹结算面板」，庆祝时长做成一个可调常量。
- **设计文档样板**：主设计文档按"3 秒 core loop / why players choose（竞品差异）/ skills & capabilities / 玩法系统（输入原语 + 风险维度 + 砖块 + 道具 + 关卡）/ 视觉 mockups / vfx requirements / 资产清单 / 3 秒理解度验证 / 平衡配置表 / 测试与验收"十节组织（198 行完整覆盖），数值全部进 canvas 表可调。
- **评星阈值按首关标定**（6050 分只拿 1 星 = 阈值过苛）；**掉球后给 ≥1s 待发球缓冲**（0.5s 自动弹出节奏太凶）。
