# B1《Fruit Merge: 2048 Harvest》水果合合乐（2048 关卡制完整版）设计文档

> 系列：B 2048 变奏家族 | 状态：✅ 完成（50 关机制关+beam search 标定+verify 41 项全绿）
> 定位：2048 关卡制标杆（B2 基于本作变奏）| 变现：合集站+未来门户重设计

## 一、游戏概述

- **核心幻想**：掉落水果合成大水果，收获"丰收"的满足感——2048 的目标导向版。
- **一句话卖点**：50 关机制关×3 盘面×4 种格子机制——每关都是新谜题。
- **差异化**（对传统 2048）：**关卡制**（每关目标不同）+**格子机制**（岩石墙/双倍格/冰冻格/传送格）+**波浪目标**（512/1024/2048/Boss/Mini 关）。

## 二、核心机制

### 2.1 基础规则（2048 核心）
- 下落式合成：相同值碰撞→合并（2+2=4...）。
- **目标**：合成指定值块（512/1024/2048）或达到目标分数。

### 2.2 关卡制（核心创新）
- **每关目标不同**：512/1024/2048/分数/Boss 关（合成 N 块 256）。
- **盘面变化**：3×3 / 4×4 / 5×5（难度递增）。
- **50 关机制关**：4 种格子机制沿难度曲线教学→复习→组合。

### 2.3 格子机制（4 种）
1. **岩石墙**：不可移动占位（减空间）。
2. **双倍格**：经过的块×2（加速）。
3. **冰冻格**：块被冻住 N 回合（限制）。
4. **传送格**：块从入口传到出口（路径变化）。

## 三、关卡/难度设计

- **难度曲线**：盘面（小→大）+机制（教学→复习→组合）+目标（512→2048）。
- **波浪设计**：每 10 关一个波浪（512 波浪→1024 波浪→2048 波浪）。
- **Boss/Mini 关**：每波浪末尾 Boss 关（大目标）+Mini 关（小目标快速过）。
- **beam search 标定**：每关保证可解（贪心 512 天花板→beam search 解到 2048）。
- **确定性可达闭环**：spawn 值+落位序列=标定序列（100/100 可达）。

## 四、变现钩子

- **hint**：提示下一步最优（beam search 一步）。
- **shuffle**：洗牌（保留块值+重新排布）。
- **rewarded ad**：看广告+5 步/换目标。
- **banner**：常驻底部。

## 五、美术/音效需求

- **美术**：水果（16 种值对应 16 种水果）、农场背景、格子机制特效（岩石/双倍光/冰冻/传送门）、合成粒子。
- **音效**：合成"嘭"（音调随奖励值）、消除"叮"、Boss 关紧张音乐、胜利欢呼。
- **mute-on-silent**：✅ 已实现。

## 六、技术要点

- **Board.ts**：盘面状态+合成逻辑+格子机制。
- **LevelGen.ts**：关卡生成（beam search 标定）。
- **Levels.ts**：50 关预生成。
- **beam search 评估**：最大块进度+空间+合并收益+相邻同值对（贪心天花板 512→beam 解到 2048）。
- **弹窗状态机锁输入**（踩坑）：避免操作在弹窗期间生效。
- **确定性可达闭环**（踩坑）：标定模拟与玩家消费完全同一序列/参数。
